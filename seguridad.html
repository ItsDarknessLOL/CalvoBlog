Seguridad

Información de despliegue

El sitio no incluye cuentas de usuario ni guarda secretos en el navegador. Netlify debe servirlo con HTTPS y los encabezados básicos definidos en netlify.toml.

Formulario

Las propuestas se procesan mediante Netlify Forms. El formulario incorpora un campo trampa para bots; revise los envíos marcados como spam desde el panel de Netlify.

Reportar un problema

Antes de publicar, agregue un correo de contacto real para reportes de seguridad. No incluya contraseñas, claves API ni datos sensibles en una propuesta.
